# Multi-modal AI Studio v0.2.0-rc.1

This release candidate is the first broadly usable public preview of the
interchangeable Jetson voice pipeline. It turns independently served ASR,
LLM/VLM, and TTS models into a browser-based conversational assistant with
session recording and latency analysis.

## Recommended Jetson quick start

The default public path is:

```text
browser microphone
  -> Speaches Faster-Whisper
  -> Gemma 4 E2B through llama.cpp
  -> Speaches Kokoro
  -> browser speaker
```

It has been exercised on Jetson Orin Nano, Jetson AGX Orin, and Jetson AGX
Thor. The bundled launchers pull the correct Jetson llama.cpp image, start the
pinned dual-SM Speaches image, download the starter models, and verify the
OpenAI-compatible APIs.

```bash
./scripts/speaches_speech.sh start
./scripts/speaches_speech.sh verify
./scripts/gemma4_llm.sh start
./scripts/gemma4_llm.sh verify
multi-modal-ai-studio --preset speaches-jetson --port 8092
```

## Additional speech paths

- NVIDIA Nemotron 3.5 ASR and Magpie TTS reference services
- OpenAI-compatible REST transcription and speech APIs
- OpenAI-compatible Realtime transcription and response-audio APIs
- NVIDIA Riva streaming ASR and TTS over gRPC
- Speaches Realtime transcription for endpointing and barge-in evaluation
- Experimental Qwen3-TTS and other OpenAI-compatible TTS services

## Evaluation features

- Browser and server-connected audio devices
- Barge-in and turn-scoped cancellation
- Live and recorded timelines for VAD, ASR, LLM, TTS, and audio playback
- Time-to-first-audio and per-stage latency measurements
- Jetson host, CPU, GPU, memory, and utilization metadata
- Session configuration snapshots, transcripts, waveforms, and thumbnails
- Voice discovery, preview, language selection, and speech-speed controls

## Known limitations

- The Jetson Speaches image is still an upstream release candidate.
- Speaches wraps VAD-delimited Faster-Whisper inference; it does not provide
  model-native incremental Faster-Whisper decoding and may not emit partial
  transcript deltas.
- Application-level text chunking can start TTS before LLM completion, but
  small chunks may sound segmented or underrun when the LLM and TTS compete
  for the same GPU. Use the disabled baseline for quality comparisons.
- Orin Nano 8 GB needs careful memory management. Stop unrelated GPU services,
  retain the small default models, and configure swap for transient CPU-side
  allocations during startup.
- Local launcher endpoints are unauthenticated and intended for trusted
  development networks.
- Headless audio remains experimental; browser WebRTC is the recommended
  public-preview path.
- TTS chunk-ready and playback-underrun visualization is tracked separately in
  [issue #59](https://github.com/NVIDIA-AI-IOT/multi_modal_ai_studio/issues/59).
