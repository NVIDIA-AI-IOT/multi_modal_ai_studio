# Voice AI Workbench 0.2.0

Prepared release notes. Publication is not complete until the GitHub Release and PyPI jobs have succeeded and their artifacts have been verified.

**Give your robot a voice. Compare models, shape its character, and measure the conversation.**

Voice AI Workbench brings independent ASR, LLM, and TTS services into one configurable conversation UI. Start with your browser's microphone and speaker, inspect latency and interruptions on the timeline, then evaluate a saved configuration with server-local USB audio. Optional camera input supports vision-language models.

## What's new

- **A local Jetson quick start:** Faster-Whisper tiny.en + text-only Gemma 4 E2B + Kokoro, including an Orin Nano path. Separate container launchers manage speech and LLM services; no Riva server setup, NGC entitlement, or hosted inference key is needed for this route.
- **Interchangeable speech APIs:** OpenAI-compatible REST and Realtime adapters, NVIDIA Nemotron ASR/Magpie reference services, and existing Riva gRPC support. Provider capabilities determine partial transcripts and audio-streaming behavior.
- **Conversation tuning:** Model/voice discovery, voice preview, speech-speed controls where supported, editable LLM system prompts, reusable presets, and an optional compact configuration layout.
- **Inspectable sessions:** Audio, speech/VAD, ASR, LLM, TTS, and barge-in lanes; CPU/GPU telemetry; recorded host/device configuration; thumbnails; and downloadable session JSON. Saved sessions retain playback timing for review.
- **Installable application:** Wheel and source distribution include the Web UI and presets. GitHub release assets include checksums and dependency manifests. The stable-release workflow publishes the same wheel and source distribution to PyPI when publishing is enabled.

## New name, compatible configurations

**Multi-modal AI Studio (MMAS)** is now **Voice AI Workbench**. The distribution and recommended CLI are `voice-ai-workbench`. The repository and Python import remain `multi_modal_ai_studio`; the legacy `multi-modal-ai-studio` CLI, existing settings location, and session formats are retained.

Use a fresh virtual environment when moving from an earlier MMAS wheel, or follow the [upgrade instructions](https://github.com/NVIDIA-AI-IOT/multi_modal_ai_studio/blob/main/docs/development/releasing.md#upgrading-an-earlier-mmas-installation). Do not install both distributions into the same environment: they share the Python package and legacy entry point.

## Install and try it

After PyPI publication, use Python 3.11 or newer:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install voice-ai-workbench==0.2.0
voice-ai-workbench --version
voice-ai-workbench --preset speaches-jetson --port 8092
```

Conversation requires separately running ASR, LLM, and TTS endpoints. The wheel does **not** include model weights, inference containers, or backend launch scripts. Follow the [README quick start](https://github.com/NVIDIA-AI-IOT/multi_modal_ai_studio/blob/main/README.md#recommended-quick-start-on-jetson) using the matching `v0.2.0` repository checkout for the scripts. Start with **Speaches on Jetson — REST**; to compare NVIDIA models, see the [Nemotron/Magpie setup guide](https://github.com/NVIDIA-AI-IOT/multi_modal_ai_studio/blob/main/docs/setup_open_models_jetson.md).

Alternatively, download the wheel and `SHA256SUMS` from the GitHub Release, verify the wheel's checksum against that manifest, and install the local file with `python -m pip install ./voice_ai_workbench-0.2.0-py3-none-any.whl`.

## Validation and known limitations

Pre-publication candidates were exercised in short English REST/browser conversations on Orin Nano and AGX Thor, including interruption recovery and saved-session review. NVIDIA Nemotron/Magpie REST and Realtime paths were additionally exercised on Thor. Exact candidate hashes, test boundaries, and publication checks are preserved in the [qualification record](https://github.com/NVIDIA-AI-IOT/multi_modal_ai_studio/blob/main/docs/releases/v0.2.0-qualification.md). Candidate results do not verify the eventual published artifact or every model/device combination.

- **Speaches Realtime is not the public baseline.** The pinned Speaches `0.9.0-rc.3` image is a separate backend release candidate. Its Realtime ASR path failed concurrent Nano conversation testing; a corrected local backend passed follow-up tests but has not been published. Updating the workbench alone does not fix that server. Use the REST preset for the public quick start.
- **Realtime transport is not model-native streaming.** Speaches Faster-Whisper processes VAD-delimited utterances and may not emit partial transcripts. Early TTS uses text chunking; small chunks can affect prosody, and insufficient throughput or shared GPU contention can cause pauses.
- **Cold start and memory matter.** First model loading can delay a response, and latency is not bounded. Small devices need memory headroom; swap does not expand GPU memory.
- **USB/headless and other providers have narrower coverage.** Validate your own acoustic setup, echo cancellation, and long-running workload. The workbench does not provide robot motion control.
- **Development-network scope:** Do not expose unauthenticated UI/model endpoints directly to the public internet. Backend containers and models have separate licenses and security lifecycles; functional qualification is not a security clearance.

TTS style-instruction and voice-cloning UI are **not included** in 0.2.0 and are deferred to future work.
