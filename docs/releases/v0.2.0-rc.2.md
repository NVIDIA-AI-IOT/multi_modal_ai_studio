# Multi-modal AI Studio v0.2.0-rc.2

Status: release candidate in preparation, not a publication or security approval. rc2 includes the functionality described in the [rc1 release notes](v0.2.0-rc.1.md), with the corrections below.

## Changes since rc1

- REST transcription converts UI locales to the language codes expected by providers such as Faster-Whisper: `ja-JP` becomes `ja`, `en-US` becomes `en`, and `zh-CN` becomes `zh`. Riva continues using locale tags. Automatic detection omits the optional language parameter.
- The REST ASR tab can explicitly refresh its model list and, for a detected Speaches model-management API, download the selected model after confirmation. Models listed in the registry are candidates, not validated installations. See [model management](../development/speech-model-management.md).
- TTS cancellation visualization matches completions that arrive before browser playback-stop acknowledgements, and does not borrow a completion from a different turn.
- A response containing reasoning but no answer produces a visible diagnostic and a `tts_skipped` event. It is not silently mistaken for a TTS hang. Reasoning is never substituted for an answer. LLM servers may still require their own reasoning/token-budget configuration; MMAS does not change a shared server's launch settings.
- Saved session JSON can be downloaded next to the filename copy button. The original file can include transcripts, configuration, and any credentials saved in that configuration; review it before sharing.

## Installation and release gates

Python version: `0.2.0rc2`. GitHub tag: `v0.2.0-rc.2`. Wheel and source distribution are prepared by the existing build workflow. Publication to GitHub, TestPyPI, or PyPI remains a separate approved step; do not assume an index upload has happened.

The wheel contains the UI and presets. ASR, LLM, and TTS services are independent. Use the matching source commit/tag for the backend launcher scripts, not an editable source installation in place of the wheel qualification test.

Record final commit, checksums, security disposition, and hardware evidence in the [rc2 qualification record](v0.2.0-rc.2-qualification.md). No tag or release should be published merely because automated tests passed.
